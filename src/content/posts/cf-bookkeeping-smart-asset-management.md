市面上的记账软件琳琅满目，但常常存在几个无法忽视的痛点：
1. **隐私泄露与过度索权**：许多商业记账软件充斥着金融借贷广告，且个人财务数据托管在第三方服务器上，令人担忧。
2. **流水记账容易放弃**：仅仅机械地记录“今天吃了 20 块钱快餐”毫无成就感，难以养成长期记账习惯。
3. **大额资产无法量化**：买了一台 15,000 元的电脑，一次性记入当月支出会导致当月账单“暴雷”，但实际上这件耐用品可以使用 3~5 年，这种单次大额支出严重失真。

为了解决这些问题，我开发了 **`cf-bookkeeping`** 智能个人记账与资产折旧平台。通过引入 **持物生命周期与日均使用成本**、**冷静期心愿单** 以及 **周期固定薪水智能回溯**，让记账变成一种审视生活消费质量的心流体验。

---

## 🌟 独特的核心功能设计

### 1. 持物大件生命周期与日均成本折旧
对于数码产品、大家电、家具等耐用大件，平台支持将其录入为 **“持物” (Things)**。
- 平台会自动记录物品的购买日期、初始价格、预期使用年限及残值。
- **动态计算日均持有成本**：例如一台 7,300 元的手机，使用 2 年后，平台实时计算其“日均使用成本”已降至每天 10 元。
- **心理正反馈**：看着昂贵物品的日均使用成本每天都在降低，不仅能促使自己物尽其用，也避免了消费主义的频繁冲动换新。

### 2. 抗冲动消费利器：冷静期心愿单
在看中某件非必需品时，强制将其先放入“心愿单”，并设定 7 天、14 天或 30 天的冷静期倒计时。
- 倒计时未结束前无法点击购买。
- 当冷静期过去后，系统会提示：“你现在还强烈想要它吗？”
- 实测表明，超过 60% 的非理性冲动消费会在冷静期结束后被主动取消，大幅减少了闲置物品的产生。

### 3. 周期固定薪水与定期账单的变额回溯 (Backfill)
工资、房租、定投等通常是每月固定日期发生的收支。
- 平台支持配置周期规则，并通过 Cloudflare 边缘定时触发器（**Cron Triggers**）在每月固定时刻自动执行记账。
- **历史回溯算法**：如果某项收入（如工资）在中途发生了薪资调整，系统支持按历史时间段设置不同的回溯金额，一键自动补齐历史月份的对账数据。

## 🛠️ 云原生 Serverless 技术架构

平台全面基于 Cloudflare 边缘生态构建，域名为 `book.b1uegrey.xyz`：

```
                    [ 手机 PWA / 电脑端浏览器 ]
                                 │
                   (已集成 cf-auth 根域免密 SSO)
                                 │
                                 ▼
                     Cloudflare Workers (Hono API)
                      ├── 资产统计与流水计算路由
                      ├── Cron 每日资产结转与自动记账
                      └── Workers AI 智能小票文本解析
                                 │
            ┌────────────────────┼────────────────────┐
            ▼                    ▼                    ▼
     Cloudflare D1        Cloudflare R2        Workers AI
     (多表关联关系模型)   (发票/物品照片附件)   (大模型轻量推理)
```

### 1. 极致轻量的边缘数据库 D1
采用 SQLite 方言的 D1 存储流水、账户、持物与心愿单数据。通过事务保证多账户转账操作的原子性：
```sql
-- 账户转账原子事务示例
BEGIN TRANSACTION;
UPDATE accounts SET balance = balance - 100 WHERE id = 'from_acc';
UPDATE accounts SET balance = balance + 100 WHERE id = 'to_acc';
INSERT INTO transactions (id, type, amount, from_id, to_id, created_at)
VALUES ('tx_123', 'transfer', 100, 'from_acc', 'to_acc', datetime('now'));
COMMIT;
```

### 2. 免流量费的 R2 图片对象存储
用户记账时拍摄的小票凭据、物品开箱照片，通过前端压缩后直传 Cloudflare R2。由于 R2 免收出站数据传输费用（Zero Egress Fees），即使每天查看历史收据照片，也无需担心流量计费账单。

### 3. PWA 原生级移动端体验
应用完整配置了 Web App Manifest 与 Service Worker，支持在 iOS Safari 或 Android Chrome 中直接点击 **“添加到主屏幕”**。打开后无浏览器顶部地址栏，全屏沉浸，秒开且流畅度媲美原生客户端。

## 💡 结语与心得

个人记账最难的从来不是技术，而是**如何设计正向激励机制以长期坚持**。

将大件消费转换为“日均持物成本”，将冲动消费约束在“冷静期心愿单”，并通过 Cloudflare 边缘 Serverless 架构实现全天候毫秒级响应，让我真正做到了持续两年以上的自发记账与资产管理。数据完全握在自己手中，纯净无广告，这也是独立开发最美妙的意义所在。
