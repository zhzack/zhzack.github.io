随着大语言模型（LLM）的飞速发展，语音交互正逐渐从生硬的“指令式问答”演进为自然、生动的 **全双工拟人通话**。然而，商业云端语音 API（如 OpenAI Realtime API）高昂的按分钟计费门槛与网络抖动延迟，使得在本地构建一套纯私有、零网络依赖的实时语音交互平台成为极具挑战与价值的方向。

近期，我在本地硬件环境（**AMD Ryzen 7 9800X3D + AMD Radeon RX 9070 XT 16GB**）上，从底层打通了从麦克风实时采音、VAD 人声切分、SenseVoice 流式转写，到本地 Ollama 大模型推理及多引擎语音合成的完整闭环，构建了 **`VoiceStudio & Realtime Voice Agent`**。

## 🎙️ 全双工实时通话流水线架构

真正的全双工拟人通话，关键在于 **“低延迟”** 与 **“随时可被用户打断 (Barge-in)”**：

```
[ 麦克风输入 ]
      │
      ▼
[ Silero VAD ] ────── (检测到人声静音 / 停顿)
      │
      ▼
[ SenseVoice-Small (INT8) ] ── (毫秒级输出文本: "请问今天天气怎么样？")
      │
      ▼
[ 本地 Ollama (Qwen2.5) ] ──── (以 Token 流式生成回答)
      │
      ▼
[ 智能标点断句缓冲区 ] ──────── (检测到逗号/句号，立即切出第一句话)
      │
      ▼
[ TTS 引擎 (Kokoro / Edge) ] ─ (首句音频并发合成，耗时 < 150ms)
      │
      ▼
[ 音频输出播放 ] ───────────── (扬声器发声；若用户突然插话，VAD 立即掐断播放)
```

### 1. 毫秒级语音转文字 (STT)
选用了阿里巴巴开源的 **SenseVoice-Small**，采用 INT8 量化后的 ONNX 运行时。搭配 **Silero VAD** 进行精准的语音活动检测：
- 在 16kHz 单声道采样率下，单次句级推理耗时仅在 **30ms~50ms** 之间。
- 支持富文本情感与语调识别（如开心、疑惑、叹气等），为后续大模型的 Prompt 注入丰富的情感先验。

### 2. 避免“哑巴等待”：智能标点切句流
传统交互往往等大模型把完整段落全部输出完成后再喂给 TTS，导致首字发音延迟高达 3~5 秒。
我设计了一个流式标点累加器：
- 当 Ollama 流式吐出文字时，遇到首个句逗符号（`，`、`。`、`！`、`？`），只要字符长度达到预设阈值（如 > 8 个汉字），立刻将当前片段切片抛入后台工作线程进行 TTS 合成。
- 第一句话的声音播放期间，大模型已经在继续生成第二句话，从而实现 **首音延迟 < 300ms** 的近乎真人对答体验。

## 🔊 多引擎 TTS Studio 音色矩阵与评测

不同的语音合成引擎在“推理速度 (RTF)”与“发音自然度/表现力”之间往往有不同的权衡。平台统一封装并横向对比了多款主流开源引擎：

| TTS 引擎 | 架构特点 | 实时率 (RTF) | 优势场景 |
| :--- | :--- | :--- | :--- |
| **`Kokoro`** | 仅 82M 参数的极速超轻量模型 | **< 0.05** (极快) | 本地全双工即时对话首选，几乎不占显存 |
| **`Edge-TTS`** | 微软云端自然音色反向提取 | **~0.15** | 极为自然的中文普通话语调（如晓晓、云希），免本地算力 |
| **`MeloTTS`** | 支持中英混合发音的多语言模型 | **~0.10** | 适合技术讲解中频繁夹杂英文专有名词的场景 |
| **`Piper`** | 嵌入式优化的本地低算力模型 | **< 0.08** | 树莓派与边缘设备部署理想之选 |
| **`F5-TTS`** | 基于非自回归 Flow Matching 的零样本克隆 | **~0.60** | 提供 5 秒参考音频，即可完美复刻任意人声声线 |

## 📊 自动化客观评测基准 (Benchmark Suite)

为了摆脱“盲听感觉”的主观偏差，我在项目中引入了自动化的客观基准测试套件：
1. **测试语料库设计**：包含日常闲聊、长文朗诵、专业技术术语、绕口令及中英文夹杂五大类标准文本。
2. **闭环回测算法**：将各引擎合成的 `.wav` 音频重新输入已校准的 SenseVoice ASR 引擎转写回文字。
3. **指标量化**：自动计算 **字符错误率 (CER - Character Error Rate)**、**文本精确率 (Accuracy)** 以及 **实时率系数 (RTF)**，最终输出标准 CSV 与 Markdown 评测报告。
