## 全新启航

本博客已全面升级为现代化的技术博客架构：

- **引擎**：[Astro 5](https://astro.build/)（极速零 JS 孤岛架构）
- **样式**：Tailwind CSS + 卡片式流式响应布局
- **交互**：Swup 平滑无刷新路由过渡 + 本地 Pagefind 静态全文检索
- **托管**：支持 GitHub Pages 与 Cloudflare Pages 双重部署
